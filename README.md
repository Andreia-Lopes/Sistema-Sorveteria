## Resumo do projeto

O projeto consiste no desenvolvimento de um sistema para ajudar na organização de uma sorveteria. A ideia é facilitar o controle das atividades do estabelecimento e deixar as informações mais organizadas e fáceis de acessar no dia a dia.

Com o sistema, buscamos tornar a rotina da sorveteria mais prática, diminuindo a necessidade de controles manuais e ajudando os responsáveis a acompanharem melhor as informações do negócio. Dessa forma, o projeto pretende ser uma solução simples e útil para melhorar a organização do estabelecimento.
